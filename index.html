How to set up Google Sheets backup
  1. Open Google Sheets and create a new spreadsheet (e.g., "Bikri Hub Orders")
  2. Go to Extensions → Apps Script
  3. Delete any existing code in Code.gs
  4. Paste the Bikri Hub Apps Script code (provided separately)
  5. Click Deploy → New deployment
  6. Select type: Web app
  7. Set "Execute as": Me
  8. Set "Who has access": Anyone
  9. Click Deploy and authorize when prompted
  10. Copy the Web App URL and paste it above
  11. Click Save Settings — Bikri Hub will offer to push existing orders
